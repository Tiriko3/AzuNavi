# Häufige Fragen

**Wo sind meine Daten?**
Auf deinem Gerät: im Datenordner (PC), im App-Speicher (Android) oder im Browser (Web-App ohne Ordner). Nirgendwo sonst.

**Ich habe das Passwort vergessen.**
Mit dem Wiederherstellungsschlüssel kannst du ein neues Passwort setzen. Ohne beides gibt es keinen Weg zurück.

**Die Web-App in Firefox hängt beim Start.**
Das war ein Fehler in Version 0.9.1 und ist in 0.9.2 behoben. Seite neu laden (Strg+F5), damit die neue Version kommt.

**Der Import findet bei meinem PDF nichts.**
Probier es mit der neuesten Version. PDF-Formulare (HHU) und der LaTeX-Tagesnachweis werden erkannt. Gescannte PDFs (nur Bilder) gehen nicht.

**Wie nehme ich meine Daten auf ein anderes Gerät mit?**
*System → Daten mitnehmen* erzeugt eine Sicherung (ZIP). Auf dem anderen Gerät einspielen.

**Ich habe eine Idee oder einen Fehler gefunden.**
Schreib ein Ticket im Projekt (*Plan → Tickets*) oder sag der Projektleitung Bescheid.
