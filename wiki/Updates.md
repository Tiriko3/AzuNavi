# Updates

| Variante | So kommt das Update |
|---|---|
| **Web-App** | Lädt sich selbst neu, sobald du online bist und die Seite öffnest. Falls die alte Version hängt: Seite neu laden (Strg+F5). |
| **Windows** | Neues Setup oder neue portable Datei aus dem neuesten Release holen und installieren bzw. ersetzen. Deine Daten bleiben im Datenordner. |
| **Android** | Neue APK aus dem Release installieren. Deine Daten bleiben erhalten. |

**Vor jedem Update:** Mach eine Sicherung unter *System → Daten mitnehmen*.

Die Version steht am PC unter *System*, auf dem Handy unter *Mehr*. Neuerungen stehen in der Beschreibung des jeweiligen Releases.
