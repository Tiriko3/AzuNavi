# Download und Installation

Die fertigen Dateien liegen auf der **Release-Seite** des Projekts (Menü *Bereitstellen → Releases*). Das jeweils neueste Release ganz oben nehmen.

> **Hinweis für Gäste:** Wenn du die Release-Seite nicht siehst, hat dein Zugang dort keine Leserechte. Frag die Person, die dich eingeladen hat, nach dem Link oder nach der Datei. Die Web-App (siehe unten) braucht keinen Zugriff auf das Projekt.

## Windows

1. Im Release die Datei **Setup** (Installer) oder die **portable** Datei herunterladen.
2. Setup: doppelklicken und den Schritten folgen. Portable: Datei an einen Ort deiner Wahl legen und starten.
3. Beim ersten Start wählst du einen **Datenordner**. Dort liegen deine Daten (Datenbank, Dateien). Der Ordner kann auch in einer Cloud liegen (zum Beispiel OneDrive).
4. Windows warnt eventuell vor einer „unbekannten“ App. Das liegt daran, dass die Datei nicht mit einem Zertifikat signiert ist. Wenn du der Quelle vertraust: *Weitere Informationen → Trotzdem ausführen*. Im Zweifel erst bei der IT nachfragen.

## Android

1. Im Release die **APK**-Datei herunterladen.
2. Öffnen. Android fragt, ob Apps aus dieser Quelle installiert werden dürfen. Das erlaubst du nur für diese eine Installation.
3. Deine Daten bleiben im Speicher der App auf dem Handy. Zum Übertragen zwischen Handy und PC gibt es die **Sicherung** (ZIP) unter *System*.
